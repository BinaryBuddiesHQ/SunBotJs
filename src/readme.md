# Sunbot.. but in js!

Create a disco bot in dev portal.
Place a config.json in root src.

# config.json

Should look something like this:
```
{
  "bot": {
    "token": "<your bot token here>",
    "clientId": "<empty>"
  },
  "mongodb": { // some dev stuff, haven't really figured this stuff out yet. Leave empty
    "connectionString": "<empty>",
    "database": "<empty>"
  }
}
```
